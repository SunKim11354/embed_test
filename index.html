클래식 음악 임베딩 검사기 V1

홈페이지의 YouTube 동영상을 하나씩 등록하여 GitHub Pages에서 실제 재생되는지 검사합니다. 결과는 이 브라우저에 자동 저장됩니다. YouTube의 자동 상태 신호만으로 성공 판정하지 않으며, 소리가 들리는지 직접 확인한 뒤 결과를 표시하세요.

1. 검사 대상 등록

홈페이지 작품 URL만으로 YouTube 영상 ID를 자동 추출할 수는 없습니다. 해당 작품 페이지에서 YouTube 영상의 공유 주소를 복사하여 넣으세요. Shorts, youtu.be, embed URL도 인식합니다.

2. 플레이어 검사

YouTube 플레이어 API 로딩 중…

실패 코드 101/150은 임베딩 제한을 나타낼 수 있고, 153은 Referer/클라이언트 식별 문제를 나타낼 수 있습니다. 소리 없이 플레이어만 나타난 경우에는 통과로 기록하지 마세요.

3. 검사 목록 및 기록

작품YouTube ID검사 결과작업

기록은 브라우저의 localStorage에 저장됩니다. 다른 기기 또는 브라우저에서는 자동 공유되지 않으므로, 작업 중간에 CSV 또는 JSON으로 백업하세요. CSV에는 홈페이지 주소와 검사 일시도 포함됩니다.
